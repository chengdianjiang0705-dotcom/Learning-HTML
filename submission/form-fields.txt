TITLE
Learning HTML

SHORT DESCRIPTION
A simple guide to Nezha, with a short story, film quotes, and notes about the website.

LONG DESCRIPTION
Nezha Story Notes is a simple introduction to Nezha, a character from Chinese mythology. It brings together a short story summary and memorable film quotes about courage, family, and choosing your own path.

The website is for readers who are curious about Nezha and want an easy place to begin. It uses short English passages rather than a detailed account of every legend or film. The film quotes are translated into English, with the film title and release year.

The four pages are Home, Story, Quotes, and About. HTML structures the content, CSS provides the colours and layout, and one small JavaScript file adds the same navigation and footer to each page. The project stays deliberately simple, with ordinary links and no accounts or games.

The project was created by Diancheng Jiang as a beginner web exercise. AI assisted with the wording and code revision. The portrait was supplied with the original exercise files; its original creator and reuse terms have not been identified.
